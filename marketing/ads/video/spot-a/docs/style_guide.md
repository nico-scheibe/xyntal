# Style guide: Novaire-style UI film, Xyntal brand

Reference: six @novaireapp TikTok ads (analysed 2026-11-02). Motion and composition from the
reference; colours and type from Xyntal (assets/brand.json, public/cosmos.css).

- Background: #07070B, starfield, ambient violet/cyan glows, faint drifting network.
- UI is extracted, not recorded: single glass cards float centred; real product crops where they
  exist (hero match cards from the live site), type + vector icons for the feature wheel.
- Glow only as a coloured edge light on the focused card; never on text.
- Type: Inter 700 for display, Inter 500/600 for UI. One gradient word per line.
- Pace: a new card every beat on the wheel, 1-3 s per UI moment in the demo, end card >= 1.9 s.
- Sound: synth house bed, UI click per card, impact on the lock, two-note bell as the match chime.
