    Zwei-Faktor-Anmeldung (2FA)

    Wird geladen …

    Mit 2FA brauchst du beim Login zusätzlich einen Code aus einer Authenticator-App – z. B. Google Authenticator, Microsoft Authenticator, 1Password oder die Passwörter-App auf dem iPhone. Wer dein Passwort kennt, kommt ohne dein Handy trotzdem nicht rein.

    1. Scanne den QR-Code mit deiner Authenticator-App.
    2. Gib den 6-stelligen Code ein, den die App für Xyntal anzeigt.
